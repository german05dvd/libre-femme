# Mapa de búsqueda orgánica — LIBRE femme

Objetivo: captar búsquedas relevantes de moda femenina en Cuba y convertirlas en visitas al catálogo y consultas por WhatsApp. La página debe responder a una intención clara; no se deben repetir palabras clave artificialmente.

## Páginas de producto

Cada producto publicado con slug y al menos una variante obtiene una URL `/producto/{slug}/`. El título, descripción, imagen, categoría, precio y disponibilidad se generan desde el catálogo. No se redactan manualmente metadatos para cada SKU.

## Reglas editoriales y técnicas

- Escribir para personas; cada página debe tener un tema propio y texto útil.
- No inventar dirección física, métodos de pago, tiempos de entrega ni políticas que no estén confirmadas.
- Mantener el catálogo como fuente de verdad para nombres, variantes, precios e inventario.
- Usar enlaces internos entre guías, categorías y productos relacionados.
- Mantener una URL canónica por página y añadir al sitemap solo páginas públicas publicadas.
- Revisar consultas e impresiones en Search Console antes de ampliar o cambiar el mapa de términos.
