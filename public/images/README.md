# Hero de LIBRE femme

Coloca aquí las dos fotografías seleccionadas para el hero de la tienda:

- `hero-main.webp`: fotografía principal, más grande. Recomendación: 1400 × 1800 px o proporción vertical 4:5.
- `hero-detail.webp`: segunda fotografía, de detalle/textura o una composición distinta. Recomendación: 900 × 1200 px o proporción vertical 3:4.

Usa WebP optimizado (idealmente menos de 350 KB por imagen) y evita incluir nombres de personas o metadatos privados en los archivos. La web ya las busca en `/images/hero-main.webp` y `/images/hero-detail.webp`.

Las imágenes no se incluyen todavía; deben ser las fotografías elegidas por la marca.
